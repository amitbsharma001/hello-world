How the page-load bar works
Timeline
0ms     browser parses <script src="lazyglobal.js"> in <head>
  ├─ fetch/XHR patched           (nothing escapes)
  ├─ CSS + bar injected           (into <html>, body not needed)
  └─ bar starts animating        ← user sees loading immediately

~50ms   body parses, content renders progressively
  └─ pill + full UI injected

~800ms  window 'load' fires (all images, css, fonts done)
  ├─ if AJAX in flight → bar keeps running (seamless handoff)
  └─ else → bar sweeps to 100% and fades
Integration — still one line
HTML 
<!-- in <head>, as early as possible -->
<script>
  window.LazyGuardConfig = {
    trackPageLoad: true,     // bar during initial page load
    pageLoadUntil: 'load',   // 'load' | 'interactive'
    minDuration:   280,
    ignoreUrls:    ['/health'],
  };
</script>
